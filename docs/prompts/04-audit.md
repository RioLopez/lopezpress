# 模板 04 — 自查/审计:全栈扫描 → 分级清单 → 修复

## 何时用
阶段性质量检查、"按标准仔细检查"、发版前审计。与模板 03 的区别:本模板是**主动扫**,不是带着现象来。

## 提示词正文(粘贴区)

```
按 lopezpress 的 AI 协作标准做一次全栈自查审计。

【范围】
<全栈 / 或指定:如"只管 internal/services 权限相关" / "前端 i18n 覆盖">

【执行要求】
1. 扫描(按风险维度,不按文件顺序):
   - 安全:权限越权、路径逃逸、注入、密钥硬编码、限流可绕过
   - 正确性:错误吞掉、边界条件、并发、事务完整性
   - 一致性:前后端契约、错误码语言、i18n 覆盖、死代码
   - 资源:低配机约束(连接池/内存/无谓查询/前端包体)
2. 每个发现必须带 文件:行号 证据链,按 P0(安全/数据损坏)/ P1(功能缺陷)/ P2(代码债) 分级,
   写入 docs/TODO.md(已有条目的更新状态,不重复造)。
3. 汇报分级清单(只列标题 + 一句话 + 位置),等我圈定修哪些再动手;
   我说"都修"才按 P0→P1→P2 顺序批量修。
4. 每修一项:回归测试同步补;门禁五命令保持全绿。
5. 完成后:更新 docs/AUDIT_<日期>.md(证据链全量存档)、TODO.md、PROGRESS、memory 日志。
```

## 预期产出
- 分级问题清单(P0/P1/P2,带证据链)
- 用户圈定后的修复 + 回归测试
- `docs/AUDIT_<日期>.md` 存档 + TODO/PROGRESS/memory 更新
