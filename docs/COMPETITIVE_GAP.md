## 2. 完全缺失（竞品普遍有，我们没有）

| # | 功能 | 谁有 | 买家影响 | 做起来的代价 |

| G-2 | **修订历史 / 版本回滚** | WP（每次保存一版）、Ghost、Halo | 改坏了没法回退，只能凭记忆重写 | 中（每次保存存一份 body 快照，加清理策略） |

| G-5 | **导入器**（WordPress WXR / Markdown 批量） | WP、Ghost、Halo、Hexo | **换不过来**——最大的销售阻碍 | 中（解析 + 去重 + 保留时间） |

| D-2 | **SEO** | slug + sitemap + RSS + robots | meta description / OG / canonical / Article 结构化数据 / 301 管理 / 站点验证 | 除 slug 外**几乎全缺**；且 SPA 让客户端 meta 对爬虫无效（Google 能跑 JS，微信/Twitter 不能） |
| D-3 | **统计** | 总浏览 + 每篇浏览（已按人/天去重） | Ghost：实时访客、来源渠道、每篇转化、按会员分层 | 无**来源(referrer)**、无**时间趋势**（有 `post_views` 表却没做图表）、无热门榜、无导出 |
| D-4 | **搜索** | `LIKE %kw%` 扫 title/body/author | Halo：Lucene 索引 + 高亮 + 筛选；Ghost：内置全文 | 无摘要高亮（列表里高亮但无匹配片段）、无排序相关度、无按分类/标签组合、**千篇以上会明显变慢** |
| D-5 | **多作者** | 三层角色 + 审核队列 | WP 5 角色 + 协作编辑；Ghost 多作者 + 作者页统计 | 无共同编辑/锁定、无"编辑/投稿者"细分、作者页无统计、无作者简介完善度引导 |
| D-6 | **分类** | 两层树 + 预设 | WP 无限层 + 自定义分类法；Halo 多层分类 + 分类模板 | 只有两层；**无自定义分类法**（比如"系列""专栏"）；无分类封面/描述 |
| D-7 | **备份** | 手动 JSON + VACUUM 快照 | WP 定时 + 云盘；Halo 内置备份 | 无定时、无异地、无"备份完整性校验"、无恢复演练引导 |
| D-8 | **权限** | root/admin/user 三层，规则齐全 | WP 细到能力(capability) | 无细粒度权限（如"只能管自己分类"）、无 API Token（只有 JWT，脚本集成麻烦） |
| D-9 | **内容运营** | 置顶 + 分类标签 | WP/Halo：相关文章、系列、专题页、面包屑、阅读量排序 | **无相关文章**、无系列/专栏、无专题聚合页、无面包屑 |
| D-10 | **RSS** | 有，摘要固定 | WP：全文/摘要可切换、按分类输出 feed | 无全文/摘要开关、无分类 feed、无 podcast/JSON Feed |
| D-11 | **国际化** | 界面中英双语 | WP：WPML；Halo：多语言插件 | 文章**不能多语言**（一个站只能一种内容语言） |

## 4. 我们比竞品强的地方（别为了抄而丢掉）

1. **部署体积**：单二进制 + 一个 `.db`，无 JVM/Node/PHP 运行时。Halo 要 JVM + 数据库，WP 要 LAMP。
2. **资源占用**：1 vCPU / 1 GB 能跑；Halo/WP 在这个配置上很吃力。
3. **权限模型的严谨度**：root 不可经任何 API 创建或提升、banned 文章冻结、备份导入有 root 闸门 —— 比很多小 CMS 严格。
4. **读者端细节**：目录高亮、阅读进度、阅读时长、灯箱、代码复制、上下篇，很多付费主题都没这么齐。
5. **浏览量去重**是服务端指纹（人/天），不是 PV 水分。
6. **图片所有权讲得清**（第 77 轮）：用户撤下自己的图之后，文件仍服务已发布文章（不破图），但**永不可被他人复用**——由 `live_key` 唯一索引保证，不靠代码纪律。竞品都有图库，但很少把"删了之后还能不能被别人用"当成数据约束来设计。

## 6. 一句话结论

**我们是"深度合格的阅读器 + 中等深度的创作工具 + 补齐了媒体与身份的运营端"。**

读者端对标 Ghost 能打 8 分；作者端从 5 分升到 7 分（编辑器、修订、导入都有，缺草稿语义与 WXR）；运营端从 4 分升到 6.5 分（统计、自动备份、图库、审计都有了，缺 SEO 与 2FA）。

真正还拦买家的只剩 **WXR 导入** 这一件——其余都是"锦上添花"或"明确不做"。这也意味着**功能层面已经接近收尾**：下一步的价值在"生产部署验证 + 真机打磨"，而不是继续堆功能。
