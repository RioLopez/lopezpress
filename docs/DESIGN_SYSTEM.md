# lopezpress 设计系统与美学规范（v1.1 · 2026-10-14）

> 前端 UI 的**唯一设计标准**。任何人（含 AI）改界面前先读本文。
> **v1.1 变更**：从“消费者（读者）视角”重构——设计从“读者要获得什么体验”倒推，而非从施工规范出发。修正 v1 的偏差：① 标杆从 SaaS 工具改为内容/出版物系；② 换掉默认 indigo；③ 前台（读者）一等公民、后台降级为工具区；④ 框架一致但门面可有个性；⑤ 性能与零干扰列为一等原则。

---

## 0. 先想清楚：我们服务谁，给他们什么体验（消费者 framing）

**两类消费者**：
- **读者（主体）**：约 90% 的时间花在**阅读页和列表页**。他们是“被服务的人”。
- **作者（次要）**：用后台和编辑器。是“使用工具的人”，不是门面。

**读者旅程与心流目标**（设计要为这个服务）：
1. **进入无摩擦**：从搜索引擎/分享链接直接落到某篇文章 → 首屏快、标题清晰、**没有弹窗/登录墙/广告/强制登录**，3 秒内能开始读。
2. **读得舒服**：排版服务长时间阅读——合适的行宽/行高/段距、暗色友好、代码/引用/图片得体。
3. **读完后愿意留下**：清晰的“下一篇/相关阅读/订阅”引导，让人想再看一篇或关注。

**作者目标**：写得顺、管得清，后台**够用、别难用**即可——它是工具区，不是门面。

> **结论：设计的天平向“读者 + 前台”倾斜。读者体验是一等公民，后台做到“清晰高效不添堵”就够。**

---

## 1. 设计哲学（读者优先版）

1. **内容优先，读者心流第一** —— 一切界面为“让人安心读完一篇文章”让路。
2. **零干扰阅读** —— 不弹窗、不拦登录墙、不塞广告；**性能即体验**（首屏快是硬指标）。
3. **移动优先阅读** —— 多数读者用手机，先保证手机上的阅读体验，再增强桌面。
4. **有记忆点的个性** —— 不做“又一个 indigo SaaS”；博客是**人设**，要有一眼能记住的气质与色调。
5. **框架一致 + 门面可有个性** —— 导航/交互/阅读页保持一致（不增加学习成本）；首页/专题/关于页允许“签名式”呈现。
6. **克制的精致** —— 精致在细节（对齐/留白/微交互），安静专业，不炫技。

> 气质定位：**一本排版讲究的独立刊物 / 一个安静有品的人的主页**，不是一个高效但性冷淡的工具。

## 2. 向别人学什么（内容/出版物系为主）

| 标杆 | 学它的什么 |
|---|---|
| **Medium** | 阅读体验黄金标准：行宽/行高/段距/引用、沉浸、读完引导下一篇 |
| **Ghost** | 博客默认主题的“得体”：出版物气质、首页有格调、不花哨 |
| **Substack** | 零干扰订阅阅读：没有弹窗和墙，一个“订阅”动作干净利落 |
| **优秀独立博客 / 少数派等内容站** | 中文阅读的排版与气质、有作者个人印记 |
| **Notion / Linear** | **仅作后台工具区参考**：清晰、高效、中性（不当前台气质） |

**核心配方（内容出版物向）**：暖中性打底 + **一个有辨识度的强调色** + 充足呼吸的留白 + 优秀的正文字排 + 零干扰。

---

## 3. 设计 Token

### 3.1 色彩
- **中性阶**（主角，可偏暖）：页面底 / 卡片 / 浮起 / 描边 / 主文字 / 次文字。
- **强调色 = 赭石/胭脂 `#b8492c`**（暗色 `#e0734f`）——已定稿，见 §10。换掉了 v1 的最大路货 indigo；赭石有书卷气与温度、对比达标。只用于：主按钮、链接、当前导航、聚焦环。
- **中性偏暖**：暖纸白 `#faf9f7` / 墨黑 `#1c1a17`（非冷灰纯黑）。
- **语义色**：成功/危险（+ private 橙），只表状态。

### 3.2 字体
- 正文用系统栈（加载快、无 FOUT），中文优先保证可读。
- **标题可考虑衬线**（出版物气质）——与正文无衬线形成对比，增强“读物感”。待定稿。
- 字级 ≤6 档，用字重（400/500/600/700）+ 颜色深浅拉层级。

### 3.3 间距 / 圆角 / 阴影 / 边框
- 间距 4 的倍数：组件内 8–16、卡片内 24、卡片间 16–24、大区块 32–48、页面 48–64。
- 圆角：控件 `--radius-sm(9)`、卡片 `--radius(12)`、大容器 `--radius-lg(16)`、胶囊 `999px`。
- 阴影：`sm` 常驻卡片、`md` hover、`lg` 浮层；要淡，不抢戏。1px 边框 + 淡阴影双保险。

### 3.4 动效
- 微交互 120–200ms；出现/消失 150–250ms；`--ease = cubic-bezier(.4,0,.2,1)`。
- 只动 `opacity/transform`；服务于反馈，不做无意义动画。**尊重 `prefers-reduced-motion`。**

---

## 4. 前台 = 一等公民（读者的地盘）

### 4.1 博客排版（灵魂，直接学 Medium）
- 正文宽度 **680–720px** 居中；正文 **16px / 行高 1.8**；段距 0.6–1em。
- 标题靠字重+字号；`h2` 可带 1px 下边框；代码块带复制按钮；引用左侧竖线。
- 阅读页：字号可调、目录、阅读进度、暗色友好、图片可点开。

### 4.2 首页 / 列表
- 首屏就是文章，不做无谓的英雄横幅；让读者尽快看到“有什么可读”。
- 列表清晰（标题+摘要+元信息），置顶/分类/标签筛选顺手。

### 4.3 零干扰与性能（一等原则）
- 无弹窗、无登录墙、无广告位；首屏加载快（低配栈天然优势，别用臃肿动画/大图破坏它）。
- 移动优先：先保证手机上读得舒服。

---

## 5. 后台 = 工具区（够用就好，降级）
- 目标从“惊艳”降为“清晰、高效、不添堵”：信息架构清楚、操作直接、表格不挤压、状态明确。
- 复用同一套 token 保证和前台不割裂即可，**不值得为后台堆设计精力**。

---

## 6. 一致 vs 个性
- **框架一致**：顶部导航、按钮、交互反馈、阅读页排版——全站统一，降低学习成本。
- **门面可有个性**：首页、专题聚合页、关于页允许“签名式”呈现，形成记忆点。别全站一张脸。

---

## 7. 暗色模式
- 不是反色，是**重新调一版**：近黑背景、表面分层、阴影加重、彩色提亮保对比。切换不闪白。

---

## 8. 可访问性（底线）
- 文字对比度 ≥4.5:1、大标题 ≥3:1；可见 focus 态；触控目标 ≥40px；图标按钮有 `title`/`aria-label`；表单有 `<label>`。

---

## 9. 改 UI 前自查清单
- [ ] 这个改动是服务“读者心流”，还是设计师自嗨？
- [ ] 手机上读得舒服吗？首屏快吗？有弹窗/墙/广告吗？
- [ ] 强调色用得克制、且有辨识度吗（不是默认 indigo）？
- [ ] 层级靠字重/字号/留白，而不是更多颜色/边框？
- [ ] 框架和站内一致吗？这个页面允许有个性吗？
- [ ] 暗色协调吗？focus/hover/禁用态定义了吗？对比度达标吗？

---

## 10. 已定稿（2026-10-14，作者授权 AI 决定）
1. **强调色 = 赭石/胭脂**：暖纸白 + 墨黑 + 赭石 `#b8492c`（暗色 `#e0734f`）。理由：indigo 是默认路货；赭石有东方书卷气与温度，辨识度高、对比达标，比朱红克制。
2. **标题用系统衬线栈**（Georgia + 宋体系），仅用于**内容标题**（站名/文章标题/正文 md 标题）；界面标题（后台/表单/按钮）保持无衬线。零字体加载开销，兼顾读物感与性能。
3. **门面 = 有节制的签名感**：刊物目录式首页 + 衬线站名 + 沉浸阅读页；个性靠排版/留白/色彩气质，不靠喧哗。

> Token 大多已在 `web/src/index.css`（现代设计系统层 + 响应式规范层）落地；v1.1 新增的“读者优先 / 换主色 / 前台重后台 / 门面个性”作为后续精修的执行标准。
