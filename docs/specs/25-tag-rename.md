# 标签改名与分类/标签计数跳转

> 状态：In Progress（第 43 轮实现）
> 关联：`docs/specs/07-admin-categories.md`、`docs/specs/08-admin-tags.md`
> 最后更新：2026-10-22

## 1. 背景

第 43 轮实测的事实：

| 能力 | 分类 | 标签 |
|---|---|---|
| 新增 | 有（`POST /api/categories`） | **无**（只能发文时自动创建） |
| 改名 | 有（`PUT /api/categories/{id}`） | **无** |
| 删除 | 有 | 有（`DELETE /api/tags/{id}`） |
| 计数 | 有 | 有 |
| 计数可点进文章列表 | **否** | **否** |

后果：

1. 标签写错了（`Golang` / `golang` / `go` 三个同义标签）只能**删掉重建**，而删除会连带清掉 `post_tags` 关联——文章标签会丢。
2. 计数是死数字，看到「Go 12 篇」却点不进去，得回首页手动选筛选，比不用后台还慢。
3. 标签/分类数量少时列表一屏看完，但没有过滤框，逐个找仍然费眼。

## 2. 目标与非目标

**目标**

- 新增 `PUT /api/tags/{id}`（改名，admin/root），语义与分类改名对齐。
- 标签管理页支持行内改名（复用分类页的交互）。
- 分类页与标签页的计数变成**可点击入口**：点击跳到首页并带上 `?category=` / `?tag=` 筛选。
- 两页各加一个**前端本地过滤框**（不新增后端接口）。

**非目标**

- 不做批量选择/批量删除（标签数量少，误删代价高且不可恢复；真正的批量诉求属于「文章批量操作」，另立 spec）。
- 不做标签合并（把 A 的关联迁移到 B）——需要事务内重挂 `post_tags`，单独评估。
- 不做「某标签下文章」的内嵌列表页——直接复用首页筛选，避免第二套列表实现。

## 3. API 契约

### `PUT /api/tags/{id}`

- 鉴权：`withAuth` + handler 内 `requireAdmin`（与分类改名一致）。
- 请求：`{ "name": "Go" }`
- 响应：`200 { "id": 3, "name": "Go" }`
- 错误：`400` 空名 / `404` 标签不存在 / `409` 重名 / `500`

## 4. 用户故事 + 验收标准（EARS）

- **US-1**：作为站主，我要修正写错的标签名而不丢文章关联。
  - **AC-1.1**：WHEN 以 admin 身份把标签 `golang` 改名为 `Go` THEN 返回 200，`tags.name` 更新，且该标签与原文章的 `post_tags` 关联**一条不少**
  - **AC-1.2**：WHEN 改名后新名称与已有标签重复 THEN 返回 409 `a tag with this name already exists`，原标签保持不变
  - **AC-1.3**：WHEN 名称去除首尾空格后为空 THEN 返回 400 `tag name is required`
  - **AC-1.4**：WHEN 普通用户（role=user）调用 THEN 403
- **US-2**：作为站主，我要从计数直接进入该分类/标签的文章列表。
  - **AC-2.1**：WHEN 点击分类行的计数 THEN 跳到 `/?category=<id>`，首页按该分类筛选并回到第 1 页
  - **AC-2.2**：WHEN 点击标签行的计数 THEN 跳到 `/?tag=<name>`，行为同上
- **US-3**：作为站主，标签变多时我能快速找到目标。
  - **AC-3.1**：WHEN 在过滤框输入关键字 THEN 列表按名称子串实时过滤（不区分大小写），不发起网络请求
  - **AC-3.2**：WHEN 过滤后无匹配 THEN 显示「无匹配」提示，清空后恢复全量

## 5. 边界与错误

| 情况 | 行为 |
|---|---|
| 改名只改大小写（`go` → `Go`） | 允许（重名检查排除自身） |
| 标签名长度 | 沿用模型 `size:64`，超长由 DB 拒绝 → 500，前端限制输入长度 |
| 计数为 0 的标签 | 计数不可点（无文章可看），显示为纯文本 |
| `?tag=` 指向已删除标签 | 首页正常渲染空列表 |

## 6. 测试要点

- 改名成功、重名 409、空名 400、不存在 404；
- 改名后关联文章数量不变（用 `post_tags` 计数断言）；
- 非 admin 调用 403。
