# 首页纯分页 + 每页数量

> 状态：In Progress（第 43 轮实现）
> 关联：`docs/specs/01-list-page.md`（本文取代其「无限滚动」交互）
> 最后更新：2026-10-22

## 1. 背景

第 43 轮之前首页是**无限滚动**：`web/src/pages/ListPage.tsx` 写死 `PAGE_SIZE = 20`，靠 `IntersectionObserver` 观察底部哨兵，滚到就追加下一页。

问题不在「一次加载全部」（实际每批只 20 条），而在**导航能力缺失**：

- 没有页码，无法回到「第 3 页」，只能重滑；
- 翻页状态不写进 URL，刷新回顶部、无法分享某页、浏览器前进后退失效；
- 追加式列表与「上一页」在实现上互斥（会重复渲染），所以现有代码直接放弃了分页控件。

博客的读者行为是**找文章**、回看旧文，不是刷信息流；Ghost / WordPress / Halo 全部采用分页而非无限滚动，正是为此。

## 2. 目标与非目标

**目标**

- 首页改为**经典分页**：一页 N 条，底部页码条可首/上/下/末跳转，URL 记 `?page=N`。
- 每页条数由**管理员在站点设置里定**（5/10/20/30，默认 10），读者不可自选。
- 刷新、分享、前进后退都保持当前页。

**非目标**

- 不做「分页 / 滚动」双模式（两套状态机并存是 bug 源头）。
- 不做读者侧「每页显示 20 条」的临时开关（会让同一 URL 对不同人含义不同，破坏可分享性）。
- 不改 `/archive`（它仍是全量列表，另立待办）。

## 3. 关键设计：size 由服务端决定

分页模式下前端**只传 `page`，不传 `size`**。

理由：`?page=3` 必须对所有人含义一致。若前端传 size，则同一个链接在「每页 10 条」和「每页 30 条」下指向不同内容，分享即失效。

- `GET /api/posts?page=N`（无 `size`）→ 服务端取 `site_config.page_size`，缺失或非法时回退 10。
- 显式传 `size` 仍然允许（后台管理页、个人中心等内部场景需要），上限 100 不变。

## 4. 页码条形态

```
« 首页  ‹ 上页   1 … 4 5 [6] 7 8 … 20   › 下页  末页   跳至 [__] 页
```

窗口规则：总页数 ≤ 7 时全部列出；否则始终显示第 1 页与最后一页，当前页 ±2，省略处显示 `…`。

## 5. 用户故事 + 验收标准（EARS）

- **US-1**：作为读者，我要能跳到任意一页并记住位置。
  - **AC-1.1**：WHEN 打开 `/?page=3` THEN 直接渲染第 3 页内容，页码条高亮 3，不出现第 1、2 页的条目
  - **AC-1.2**：WHEN 点击页码 THEN URL 变为 `?page=N`，列表整体替换为目标页内容（不追加）
  - **AC-1.3**：WHEN 刷新页面 THEN 仍停留在同一页（URL 驱动，非组件内 state）
  - **AC-1.4**：WHEN 页码超出总页数（如 `?page=999`）THEN 服务端返回空列表且 `total` 正确，前端显示空状态并提供「回到第 1 页」
- **US-2**：作为站主，我要控制每页条数。
  - **AC-2.1**：WHEN 在后台站点设置选择 5/10/20/30 并保存 THEN 首页每页条数随之改变，且 `?page=N` 语义保持
  - **AC-2.2**：WHEN 配置值缺失或非法 THEN 回退 10（不报错、不留空页）
- **US-3**：作为站主，我不希望筛选与分页打架。
  - **AC-3.1**：WHEN 改变搜索词 / 状态 / 分类 / 标签筛选 THEN 页码重置为 1
  - **AC-3.2**：WHEN 处于第 5 页且切换筛选 THEN 新结果从第 1 页开始，不保留越界页码

## 6. 边界与错误

| 情况 | 行为 |
|---|---|
| `?page=abc` | 400 `page, size and category must be integers`（既有契约不变） |
| `?page=0` / 负数 | 归一为第 1 页 |
| 筛选后总页数 < 当前页 | 显示空状态 + 「回到第 1 页」 |
| 无文章 | 空状态（沿用现有文案与图标） |
| 登录用户 | 仍能看到自己的 private / pending / rejected 并带状态徽标 |

## 7. 迁移与影响面

- `site_configs` 新增 `page_size INTEGER DEFAULT 10`。**该表已存在，不能走 AutoMigrate**（陷阱 1），须手工迁移 `ALTER TABLE ... ADD COLUMN`，由 `schema_migrations` 门控。
- `GET /api/site-config`（公开）新增 `page_size` 字段。
- `PUT /api/admin/site-config` 接受 `page_size`，服务端钳制到 5/10/20/30（非法值回退 10）。
- 前端删除 `IntersectionObserver` 相关约 30 行与 `loadNext`/`loadingMore` 状态。

## 8. 测试要点

- 服务层：无 `size` 时按站点配置取页大小；配置非法回退 10；`page` 越界返回空 items + 正确 total。
- 前端：类型检查 + 生产构建通过；手动验证 `?page=2` 直达。
