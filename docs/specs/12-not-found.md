# 404 页（兜底路由）

> 状态：Done（代码已实现，本 spec 首次补写；第 18 轮逐条核验后转 Done）
> 路由：任意未匹配路由（wouter 兜底 `Route component`）
> 权限：公开
> 轮次：第 3 轮
> 最后更新：2026-09-20

## 1. 目标

访问不存在的路径时给出友好的 404 提示并引导回首页，避免白屏。

## 2. 用户故事 + 验收标准（EARS）

- **US-1**：作为访客，我要在路径不存在时得到清晰提示。
  - **AC-1.1**：WHEN 访问未匹配路由 THEN 显示 404 页面（标题 404 + 说明文案）
  - **AC-1.2**：WHEN 点「回首页」THEN `navigate('/')`（SPA 跳转，15 轮已修原生跳转 404 循环）

## 3. 前端

- **布局**（ASCII）：

```
┌───────────────────────────┐
│ 顶栏（Layout，登录态视情况）│
│  notfound（居中）          │
│   h1 404                  │
│   说明文案                │
│   [回首页]                │
└───────────────────────────┘
```

- **组件树**：`Layout > NotFoundPage`
- **关键交互**：
  - 无数据加载，纯静态
  - 「回首页」`navigate('/')`（SPA，不触发整页重载）
  - wouter 的兜底 `<Route component={...}>`（无 `path`）捕获所有未匹配
  - ⚠️ 兜底 Route **必须包在 `<Switch>` 内**：wouter 在非 `Switch` 模式下会渲染**所有**匹配的
    Route，无 `path` 的那条匹配一切，会导致 404 页出现在每个页面底部（第 19 轮修复该 bug）
- **路由**：兜底（最后一条 `Route`）
- **i18n 键**：`notfound.text`、`notfound.home`
- **共享组件依赖**：`Layout` / `i18n` / `router`
