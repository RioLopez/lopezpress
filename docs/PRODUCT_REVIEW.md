## 3. 让我愿意掏钱的地方（有证据）

1. **真的轻**。一个可执行文件 + 一个 `.db` 文件就是全部，没有 Redis、没有 Node 运行时、没有容器编排。搬家用 `scp` 就够了。
2. **快**。列表 5.7 ms，服务启动 5 秒。
3. **阅读页是认真做过的**：目录带当前章节高亮、顶部阅读进度条、字数、预计阅读时长、图片灯箱、代码块一键复制、上一篇/下一篇。很多付费主题都做不到这么齐。
4. **权限是真的做了**，不是摆设：root/admin/user 三层，root 不能被任何接口创建或提升，删除/封禁/审核各有门。
5. **安全细节**：首启随机密码 + 强制改密 + 改密后吊销旧 token；登录限流双桶（IP + 账号）+ 5 次失败锁定；分页参数非法直接 400 而不是静默降级。
6. **永久链接 + 旧链接永久保留**，sitemap/RSS 自动用新链接。迁移成本最低的那种做法。
7. **管理闭环完整**：审核队列 → 封禁库 → 退回作者 → 永久删除 → 回收站，一条链都能走通。

## 4. 会让我皱眉甚至要求退款的地方

### P0（影响"能不能用起来"）

| # | 问题 | 证据 | 影响 |
|---|---|---|---|
| B-1 | **首启密码只打印到 stderr** | 启动横幅在 stderr，`*.log` 里没有 | 用 Docker/systemd 部署时若没接日志，买家**根本不知道密码**，只能跑 `-reset-root-password` 才能进门。这是新生流失点 |
| B-2 | **没有实测过的部署包** | 仓库有 `deploy/docker/`，但从未 `docker build` 过（开发机无 Docker）；也无 HTTPS 一键 | 买家要自己写 nginx/systemd/证书，等于"卖代码不卖部署" |
| B-3 | **迁移路径缺失** | 无导入器（WordPress XML / Markdown 批量 / Hexo） | 有存量博客的人换不过来，直接放弃 |

### P1（能用，但明显不专业）

| # | 问题 | 说明 |
|---|---|---|
| B-4 | 改密前所有后台接口 403 裸英文 | UI 会跳 `/change-password`（`LoginPage:28`），但 API 调用方/脚本会一脸懵 |
| B-5 | 没有草稿态 | 第 22 轮把 `draft` 删了，写一半只能存"私密"，语义不对（私密=已完成的非公开文章） |
| B-6 | 社交分享无卡片 | 纯 SPA，微信/Twitter 抓不到 OG；需要 SSR 或预渲染，架构级改动 |
| B-7 | 备份只有手动 | 没有 cron/定时、没有推送到 S3/WebDAV。数据安全靠站主自觉 |
| B-8 | 外观几乎不能改 | 无主题、无布局开关、无字体/配色面板（只有阅读页字号） |
| B-9 | 审核流对单人站是空的 | 一个人写文章时"内容审核"永远是 0 条，菜单显得多余（可作为可选功能关闭） |
| B-10 | 术语不统一 | 改密接口字段叫 `current_password`，常见约定是 `old_password`；集成方会踩 |

### P2（细节）

- sitemap 单文件（文章上万会超 50k URL 上限，需 sitemap index）
- 图片只支持本地 + SM.MS，没有 S3/R2
- 没有 2FA、没有登录设备管理（Halo 有）
- 内容单语（界面中英双语，文章不能多语言）
- 无 RSS 全文/摘要开关

| 草稿 | ❌ | 用"私密"顶 |
| 定时发布 | ❌（明确不做） | |
| 评论 | ❌（明确不做） | |
| 图片上传 | ✅ | 本地 + SM.MS |

**结论**：作为**个人技术博客**，功能面**够了**，而且深度不错；作为**要卖给不折腾的人的商业产品**，缺三样：部署包、导入器、定时备份。

## 6. 三种角色分别体验如何

**站主（就是我）**：装起来爽，写起来顺，管起来清楚。但"改外观"和"定时备份"缺失会让我觉得这是**开发者自用工具**，不是商品。

**作者（普通用户）**：写文章 → 进待审 → 收到驳回意见 → 改完重投。链路通。但没有草稿、没有自动保存到云、没有预览链接分享给别人看。

**读者**：不用登录就能读（可关），分页、目录、分享、RSS 都有。**这是最完善的一面**。

## 7. 我的出价与推荐

- **推荐给**：自己会一点 Linux、想要一个轻、快、不折腾的 Markdown 博客的人；内部知识站。
- **不推荐给**：要从 WordPress/Hexo 搬家的人（没导入器）；要靠评论做社群的人；要挑主题换皮的人。
- **我愿意付**：一次性 **￥99–199**（含一年更新），或开源免费 + ￥299/年 运维支持。**不会**为它付 ￥800+ 的"商业 CMS"价 —— 因为它缺部署自动化、迁移工具、主题体系这三样商业产品的基本配套。

## 8. 如果我是卖家，下一轮先修这 6 件

1. **部署包**：`docker compose up` 一条命令起全站（nginx + 后端 + HTTPS 自签/Let's Encrypt 脚本），并在真实 Docker 里跑通、写进 README。
2. **首启密码可控**：支持 `ADMIN_INITIAL_PASSWORD`（已有）+ 把横幅同时写进 `data/FIRST_BOOT.txt`，并在首屏引导"先改密码"。
3. **导入器**：Markdown 文件夹 / WordPress XML 批量导入（标题、正文、分类、标签、时间）。
4. **定时备份**：内置每日快照 + 保留 N 份 + 可选 WebDAV/S3 推送。
5. **草稿态**：把 `draft` 加回五态之前（作为第六态），编辑器"保存草稿"。
6. **外观**：至少给 3 套配色/两种首页布局的开关，不改代码能换脸。
